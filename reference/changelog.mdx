Coffee Tycoon has been actively updated since its initial release. Each version brings new mechanics, quality-of-life improvements, and bug fixes. The entries below cover all documented releases, starting with the most recent.

<AccordionGroup>
  <Accordion title="v1.13.4 (latest)">
    **Release date:** current

    - **Golden Upgrades Always Visible:** All golden upgrades are now always shown in the upgrades panel. Locked upgrades appear in gray instead of being hidden entirely.
    - **Bug fix:** Fixed an issue where golden upgrades would disappear from the panel after completing a prestige.
  </Accordion>

  <Accordion title="v1.13.3 – Instant Brew">
    **Release date:** Feb 8, 2026

    - **Instant number updates:** All number displays update immediately without animation delay.
    - **Golden Coffee spending:** The multiplier and Golden Coffee counters refresh the moment you spend, with no lag between action and display.
    - **Progress bar updates:** Both the prestige progress bar and the golden upgrade progress bar now update instantly.
    - **Smoother UI experience:** Removed all animation delays across the interface for a more responsive feel.
  </Accordion>

  <Accordion title="v1.13.2 – Golden Gains">
    **Release date:** Feb 8, 2026

    This was a major update introducing the Golden Coffee prestige system and a suite of new player-facing tools.

    - **Golden Coffee System:** Prestige resets your run and rewards you with Golden Coffee, which provides permanent production multipliers that persist across all future runs.
    - **Golden Upgrades:** A new category of permanent upgrades that survive prestige resets, including automation features accessible through the Upgrades tab.
    - **Offline coffee calculation:** The game now calculates coffee earned while you were away, using a 5-minute minimum threshold before offline gains apply.
    - **Settings panel:** A new settings button opens a panel with toggles for notifications, quick keys, number display format, and a progress reset option.
    - **Save export/import:** Export your entire game state as a text string. Paste it into another browser or device to transfer your progress.
    - **Erase progress:** Permanently wipe all game data from a dedicated option in the settings panel. Requires confirmation before executing.
    - **Extended number support:** Abbreviations now cover numbers up to trigintillion (10^96), supporting deep late-game coffee totals.
  </Accordion>
</AccordionGroup>

## About version numbering

Patch releases (e.g. v1.13.3, v1.13.4) contain bug fixes and targeted improvements. Minor releases (e.g. v1.13, v1.14) introduce new systems or major features. The version number shown in the game's title bar and the in-game version modal always reflects the currently running build.

<Note>
The in-game version modal (accessible via the **i** button in the header) shows the two most recent release entries. This page documents all versions with full detail.
</Note>
